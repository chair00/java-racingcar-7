# 2주차 우테코 프리코스 : 자동차 경주
***
간단한 자동차 경주 게임을 구현한다.
## 구현할 기능 목록
***

### 자동차 이름 입력받기
* (,)로 자동차 이름을 구분하여 저장한다.
* 자동차는 하나의 객체를 가진다.
* 예외
  * 공백을 입력할 경우 ex) "", " " ...
  * 중간에 공백이 들어갈 경우 ex) "1,  ,2"
  * 자동차 이름이 중복될 경우 ex) "hi, op, hi"
  * 자동차 이름이 5자를 초과할 경우 ex) "abcdef,hi,op"

### 주어진 횟수 입력받기
* 횟수를 입력받아 저장한다.
* 예외
  * 공백을 입력할 경우
  * 양수가 아닐 경우 (문자열, 음수, 소수 등)
### 자동차 이동
* 종류 : 전진(1) / 멈춤(0)
* 전진 조건 : 0~9 사이의 랜덤한 숫자를 뽑고 4 이상일 경우 전진한다.
### 차수별 실행 결과 출력하기
* 매 회마다 자동차 이동을 실행하고, 그에 따른 결과를 출력한다.
* 출력 형태
```agsl
a : ---
b : -
c : 
```
### 우승자 계산하기
* 우승자는 한 명 이상일 수 있다.
* 현재 가장 많이 전진한 사람이 우승자이다.
* 우승자는 list에 저장한다.
### 우승자 출력하기
* 저장한 우승자를 출력한다.
* 출력 형태
```agsl
최종 우승자 : a, b
```
